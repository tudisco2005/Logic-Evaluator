# WIP: Calcolatore di espressioni logiche

Questo progetto è un calcolatore di espressioni logiche che permette di valutare espressioni booleani utilizzando operatori logici come AND, OR e NOT.

include:
- sottoinsieme di operatori logici: AND, OR, NOT, XOR, IMPLIES, IFF
- supporto per variabili booleane
- parentesi per raggruppare le espressioni

permete di inerire un espressione logica:
- settare i valori delle variabili e ottenere il risultato dell'espressione.
- calcolare la tabella di verità dell'espressione logica.
- controntare 2 espressioni logiche e verificare se sono equivalenti attraverso le loro tabele di verita
